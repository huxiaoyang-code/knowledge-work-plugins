# 通信研究连接器

沿用 bio-research 的能力类别设计：Skill 描述所需能力，具体服务由运行时配置替换。下表是接入目标，不代表服务已部署、付费全文可访问或设备已连接。

| 能力类别 | 用途 | 可选实现或来源 | 阶段 |
|---|---|---|---|
| 文献检索与全文 | 找相近工作、读取证据 | 已授权文献 MCP/API；IEEE Xplore、OpenAlex、Semantic Scholar、Crossref、arXiv 等来源适配器 | 研究、评审、执行按需 |
| 标准与工程资料 | 核对版本、模型和实现条件 | 已获访问的 3GPP/IEEE 文档和设备手册 | 研究、评审、执行按需 |
| 课题与评审 | 提交不可变稿件、领取任务、提交意见 | 本目录配套本地控制后端 | 按运行时身份授权 |
| 仿真实验 | 排队、执行、查询与读取产物 | Python/Sionna、ns-3、MATLAB Worker | 初稿通过后 |
| 实物实验 | 设备预约、预检、执行与数据定位 | GNU Radio/UHD、SDR/USRP Worker | 初稿通过并满足设备条件后 |
| 论文产物 | 数据图、编译与研究包 | 已安装的绘图、LaTeX/文档工具 | 初稿通过后 |

各 profile 的源 `.mcp.json` 不预填未经验证的远程端点。管理器在物化当前阶段时配置实际控制后端；外部连接器需明确加入相应阶段的配置，不将执行凭据放入研究或评审包。

MCP 负责任务提交与状态/证据读取，实时 IQ 流由设备执行程序处理。后端拒绝无效版本、错误身份或未获批课题；提示词和工具隐藏不能替代宿主隔离、文件权限或设备授权。
